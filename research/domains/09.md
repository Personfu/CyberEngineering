# HUBBLE · AI Systems and Bounded Automation

**Evidence:** Proposed domain research framework. The equations below are author-defined candidate models, not measured findings or requirements quoted from standards.

**Research focus:** Calibrated decisions, abstention and evidence traceability.

## Governing model

```text
Brier = mean_i (p_i-y_i)^2; utility = TP b - FP c - abstentions a
```

Probabilities must come from an independently calibrated model. Thresholds optimize declared decision costs on validation data only; utility weights require owner elicitation and sensitivity analysis.

**Competing models:** Rule-based queue; uncalibrated model; always-abstain policy; same model without evidence check.

**Required record schema:** Case identifier, time split, evidence availability, score, label provenance, recommendation, human outcome. Extend the schema with provenance digest, units, coverage window, collection permission, missingness reason and transformation revision. Use explicit null values for missing observations; do not turn missing into zero.

## Evaluation contract

Measure Brier score, risk vs coverage, unsupported assertion rate, false-alert budget, human correction cost. Freeze a mission-specific primary endpoint and acceptable resource cost before tuning. Compare the candidate and baseline on the same scenario/partition. Include a no-intervention or null fixture to detect accidental leakage. Report uncertainty at the independent unit—scenario, channel, device or team—and analyze the worst-performing subgroup rather than relying on a portfolio average.

**Adverse cases:** Missing evidence; contradictory sources; benign drift; unseen channel; reduced prevalence.

**Graduate challenges:** Temporal leakage; unsupported explanations; selective labels; workload-dependent intervention. For each challenge, distinguish a limitation of the estimator from a limitation of available evidence. Ask whether the parameter is identifiable, whether the mechanism transfers to a new environment and which observation could distinguish rival explanations.

**Resource plan:** Offline curated cases and public telemetry; model output is analysis advice with bounded authority. Before implementation, produce a concrete bill of materials, input size, memory/storage estimate, runtime bound and personnel-hours estimate. No universal cost or readiness claim is made here.

## Applicable data and its limits

[Telemanom SMAP/MSL anomaly data and original study](https://github.com/khundman/telemanom). Spacecraft anomaly detection; benign operational anomalies do not label cyber compromise. Hold out channels/time; avoid random overlapping window splits and inflated point-adjusted recall; report per-event as well as per-timestamp scoring. Resource budget: Array data and Python ecosystem; size and dependencies must be checked at pinned revision. Current status: author repository inspected; NASA paper https://ntrs.nasa.gov/citations/20210008188. Access/rights: Repository license and dataset terms require review before redistribution.
