# WB24 · Test the recovery path

**Physical device · Response and resilience · Applied**

Demonstrate restoration rather than only normal startup.

## Materials

Owned noncritical fixture and a model-appropriate recovery mechanism.

## Procedure

1. Preserve a known-good configuration/artifact.
2. Make a reversible noncritical change.
3. Restore, repeat the same functional observation and retain both receipts.

## Expected result

An actual restoration result under recorded conditions; hardware execution remains unclaimed until performed.

## Failure cases and interpretation

Do not rely on the overwritten image as the only recovery path or erase unknown storage.

## Record

Keep the input/source version, command, relevant output and interpretation together. Label a fixture synthetic. Physical-device work needs the actual model, firmware and conditions. Do not report an unrun exercise as passed.
