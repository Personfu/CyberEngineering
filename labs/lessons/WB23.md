# WB23 · Design a detector negative control

**Physical device · Privacy and inference · Applied**

Test whether a detector label follows evidence or a loose identifier heuristic.

## Materials

Owned labeled positive/negative reference devices; minimized non-sensitive logs.

## Procedure

1. Define the actual observable input.
2. Blind fixture labels and count errors.
3. Change identifiers/conditions and record false positives and missed detections.

## Expected result

A bounded confusion matrix with unobservable cases, not an assumption about nearby people.

## Failure cases and interpretation

A BLE name/OUI or RSSI is not a camera/operator identity or precise location.

## Record

Keep the input/source version, command, relevant output and interpretation together. Label a fixture synthetic. Physical-device work needs the actual model, firmware and conditions. Do not report an unrun exercise as passed.
