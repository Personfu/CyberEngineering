# WB12 · Set up a role-specific mesh node

**Physical device · Off-grid systems · Applied**

Choose tracker, keyboard node, solar node or PoE gateway by its actual role.

## Materials

Owned model-specific node(s), correct regional RF hardware and current target image.

## Procedure

1. Record role and exact board.
2. Set the documented region/firmware target.
3. Run a controlled stationary baseline before changing placement.

## Expected result

Retain model/configuration, delivery counts, missing messages and power conditions.

## Failure cases and interpretation

M1/M5, V4/V4-R8 and OLED/e-paper targets are not interchangeable.

## Record

Keep the input/source version, command, relevant output and interpretation together. Label a fixture synthetic. Physical-device work needs the actual model, firmware and conditions. Do not report an unrun exercise as passed.
