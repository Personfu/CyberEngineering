# WB04 · Inspect a UF2 structure

**Offline fixture · Firmware · Foundation**

Distinguish a valid block structure from authenticated, board-compatible firmware.

## Materials

A UF2 obtained from an official source, or the synthetic block constructed by the parser tests.

## Procedure

1. Check whole 512-byte blocks.
2. Inspect magic values and complete sequence.
3. Keep structural validity separate from family compatibility and signatures.

## Commands

Run from the repository root unless the walkthrough gives a different checkout/directory.

```bash
python -m unittest discover -s tests -p test_benchkit.py -v
```

## Expected result

Tests accept a deliberately constructed complete block and reject corrupted/truncated sequences.

## Failure cases and interpretation

No UF2 from this exercise is reported as flashed or bootable; do not write synthetic parser fixtures to hardware.

## Record

Keep the input/source version, command, relevant output and interpretation together. Label a fixture synthetic. Physical-device work needs the actual model, firmware and conditions. Do not report an unrun exercise as passed.
