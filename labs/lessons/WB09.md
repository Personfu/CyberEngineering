# WB09 · Calculate an energy budget

**Offline fixture · Power engineering · Foundation**

Turn explicit duty/current assumptions into a planning estimate.

## Materials

Battery-side active/idle currents at one consistent voltage.

## Procedure

1. Write the assumed workload fractions.
2. Run the weighted-current calculation.
3. Vary one assumption and record the sensitivity.

## Commands

Run from the repository root unless the walkthrough gives a different checkout/directory.

```bash
python -m labtools.benchkit power --capacity-mah 1200 --active-ma 80 --idle-ma 5 --duty 0.1
```

## Expected result

12.5 mA average and 76.8 estimated hours using 80% usable capacity.

## Failure cases and interpretation

This excludes aging, temperature and nonlinear discharge. It is not a measured runtime claim for a named node.
