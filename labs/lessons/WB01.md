# WB01 · Record a bench inventory

**Offline fixture · Reproducibility · Foundation**

Separate host/tool evidence from an assumed board identity.

## Materials

Python 3.12; no attached device required.

## Procedure

1. Run the read-only inventory.
2. Inspect the serial candidates, if any.
3. Write the actual board identification as unknown until verified separately.

## Commands

Run from the repository root unless the walkthrough gives a different checkout/directory.

```bash
python -m labtools.benchkit inventory
```

## Expected result

JSON identifies the Python/platform and candidate paths; devices_opened is false. An empty candidate list is a valid observation.

## Failure cases and interpretation

A path is not a model. A USB data cable, boot mode, OS permission or absent device can explain no candidates.

## Record

Keep the input/source version, command, relevant output and interpretation together. Label a fixture synthetic. Physical-device work needs the actual model, firmware and conditions. Do not report an unrun exercise as passed.
