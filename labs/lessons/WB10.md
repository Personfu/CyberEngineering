# WB10 · Build an exact ESP32 target

**Physical device · Embedded development · Applied**

Match MCU, display, keyboard, partitions and peripherals to a supported build.

## Materials

An owned board and its exact current manual/release.

## Procedure

1. Inventory the complete target.
2. Build using the project-pinned SDK/environment.
3. Follow the official install/recovery route and test one desired function.

## Expected result

Record a real build result, installed version and functional observation. Hardware execution is not claimed by this repository.

## Failure cases and interpretation

A matching chip alone does not establish matching carrier pins or a valid artifact layout.

## Record

Keep the input/source version, command, relevant output and interpretation together. Label a fixture synthetic. Physical-device work needs the actual model, firmware and conditions. Do not report an unrun exercise as passed.
