# WB02 · Verify firmware bytes

**Offline fixture · Supply chain · Foundation**

Match an artifact to a separately recorded expected SHA-256.

## Materials

The synthetic example manifest and text fixture; neither is firmware.

## Procedure

1. Read the fixture manifest and identify its expected digest.
2. Run the helper with that exact digest.
3. Change one digest character and confirm refusal.

## Expected result

A correct digest returns verified=true and the byte count. The altered digest returns exit 1.

## Failure cases and interpretation

Do not replace an expected digest with the observed value after a mismatch; a hash match alone does not authenticate a publisher.

## Record

Keep the input/source version, command, relevant output and interpretation together. Label a fixture synthetic. Physical-device work needs the actual model, firmware and conditions. Do not report an unrun exercise as passed.
