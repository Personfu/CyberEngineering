# WB15 · Recover a Linux handheld

**Physical device · Linux and resilience · Applied**

Prove a complete carrier/image/peripheral combination and a separate recovery medium.

## Materials

Exact owned compute module/carrier, official image and known-good removable medium.

## Procedure

1. Record the whole machine.
2. Verify the image and explicitly identify target storage.
3. Boot, test the needed peripherals, then boot the independent recovery medium.

## Expected result

Record image/kernel, keyboard/display/storage checks and a real restoration observation.

## Failure cases and interpretation

No guessed disk-write command is supplied. A shared enclosure does not imply a shared image.

## Record

Keep the input/source version, command, relevant output and interpretation together. Label a fixture synthetic. Physical-device work needs the actual model, firmware and conditions. Do not report an unrun exercise as passed.
