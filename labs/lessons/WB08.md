# WB08 · Measure message delivery

**Offline fixture · Communication systems · Foundation**

Keep missing observations separate from observed latency.

## Materials

Ten fictional message rows, with synchronized fixture timestamps.

## Procedure

1. Count sent and observed rows.
2. Compute delivery and latency for observed rows only.
3. Explain what missing data and clock disagreement would change.

## Commands

Run from the repository root unless the walkthrough gives a different checkout/directory.

```bash
python -m labtools.benchkit telemetry labs/fixtures/messages.csv
```

## Expected result

10 sent, 8 observed, 2 missing, delivery fraction 0.8, median latency 60 ms.

## Failure cases and interpretation

No radio range or product comparison follows from this synthetic dataset. Duplicate sequences and receive-before-send inputs fail.
