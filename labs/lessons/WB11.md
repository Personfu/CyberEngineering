# WB11 · Write a Flipper external app

**Physical device · Application development · Applied**

Build a harmless logging application and understand FAP API/RAM constraints.

## Materials

Pinned official firmware SDK and examples/flipper_hello.

## Procedure

1. Copy the authored app into applications_user.
2. Build with fbt using the exact SDK.
3. On an owned device, follow the official launch path and inspect the startup log.

## Expected result

A FAP build and actual log are separate evidence. The example has not been physically run here.

## Failure cases and interpretation

External app code consumes RAM and requires compatible API metadata; a filename is insufficient.

## Record

Keep the input/source version, command, relevant output and interpretation together. Label a fixture synthetic. Physical-device work needs the actual model, firmware and conditions. Do not report an unrun exercise as passed.
