# WB19 · Observe a local web application passively

**Optional tool · Application security · Applied**

Pair a request/response with a passive finding without generating attack traffic.

## Materials

Owned local fixture and disposable browser profile; optional Burp or ZAP.

## Procedure

1. Start the fixture.
2. Observe one request with active actions disabled.
3. Trace any passive alert to the exact message/rule and discuss false positives.

## Expected result

A bounded local request/response record; no scanner/exploitation result is claimed.

## Failure cases and interpretation

Interception, passive history and active scanning are different actions. Avoid unrelated personal sessions.

## Record

Keep the input/source version, command, relevant output and interpretation together. Label a fixture synthetic. Physical-device work needs the actual model, firmware and conditions. Do not report an unrun exercise as passed.
