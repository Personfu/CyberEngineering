# WB18 · Cross-check a cryptographic digest

**Optional tool · Evidence integrity · Applied**

Compare two implementations on the same harmless bytes.

## Materials

OpenSSL CLI and the authored text fixture.

## Procedure

1. Calculate SHA-256 with OpenSSL.
2. Compare with the manifest and Python helper.
3. Change a copy and explain the mismatch.

## Commands

Run from the repository root unless the walkthrough gives a different checkout/directory.

```bash
openssl dgst -sha256 labs/fixtures/example.bin
```

## Expected result

The digest matches the fixture manifest exactly; changed bytes do not.

## Failure cases and interpretation

Integrity and source authentication are different claims.

## Record

Keep the input/source version, command, relevant output and interpretation together. Label a fixture synthetic. Physical-device work needs the actual model, firmware and conditions. Do not report an unrun exercise as passed.
