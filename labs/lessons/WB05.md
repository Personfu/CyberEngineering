# WB05 · Find pin-map conflicts

**Offline fixture · Hardware integration · Foundation**

Separate a legitimate shared signal from conflicting functions assigned to one pin.

## Materials

Two authored JSON net fixtures.

## Procedure

1. Run the shared-clock fixture.
2. Run the conflicting chip-select fixture.
3. Explain which checks still require a schematic and electrical review.

## Commands

Run from the repository root unless the walkthrough gives a different checkout/directory.

```bash
python -m labtools.benchkit pincheck labs/fixtures/pins-good.json
python -m labtools.benchkit pincheck labs/fixtures/pins-conflict.json
```

## Expected result

First fixture succeeds with three unique pins; second fails on pin 5.

## Failure cases and interpretation

Equal net names do not validate voltage, current, timing or bus arbitration.

## Record

Keep the input/source version, command, relevant output and interpretation together. Label a fixture synthetic. Physical-device work needs the actual model, firmware and conditions. Do not report an unrun exercise as passed.
