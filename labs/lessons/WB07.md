# WB07 · Decode a fictional BLE advertisement

**Offline fixture · Protocols · Foundation**

Inspect length/type/value fields without inferring a device identity.

## Materials

Hex bytes containing Flags and the fictional local name LAB1.

## Procedure

1. Decode the supplied bytes.
2. Identify the length, type and payload separately.
3. Run the truncated example and retain its error.

## Commands

Run from the repository root unless the walkthrough gives a different checkout/directory.

```bash
python -m labtools.benchkit ble-decode 02010605094c414231
python -m labtools.benchkit ble-decode 0509ff
```

## Expected result

The first yields two fields including LAB1; the second fails as truncated.

## Failure cases and interpretation

A local name can be chosen by a device. No camera, operator or vendor identity follows from this decode.

## Record

Keep the input/source version, command, relevant output and interpretation together. Label a fixture synthetic. Physical-device work needs the actual model, firmware and conditions. Do not report an unrun exercise as passed.
