# WB17 · Inspect a binary you wrote

**Optional tool · Reverse engineering · Applied**

Connect source, compiled behavior and decompiler reconstruction.

## Materials

C compiler; optional Ghidra; examples/benign_counter.c.

## Procedure

1. Build a debug version into /tmp.
2. Run it and record output.
3. Inspect main/loop in Ghidra and compare an optimized build.

## Commands

Run from the repository root unless the walkthrough gives a different checkout/directory.

```bash
cc -O0 -g examples/benign_counter.c -o /tmp/nightshift-counter
/tmp/nightshift-counter
```

## Expected result

The executable prints observed=3. Ghidra interaction is an optional manual exercise.

## Failure cases and interpretation

Do not download unknown executables or call decompiled text the original source.

## Record

Keep the input/source version, command, relevant output and interpretation together. Label a fixture synthetic. Physical-device work needs the actual model, firmware and conditions. Do not report an unrun exercise as passed.
