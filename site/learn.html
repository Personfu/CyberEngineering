A local HTTP tutorial

From the repository root, start the supplied harmless web fixture. Open a second terminal to inspect its response.

python -m http.server 8765 --bind 127.0.0.1 --directory foundations/fixtures/web
curl --noproxy '*' --include http://127.0.0.1:8765/health.json

Read the output: HTTP status, Content-Type and JSON body describe different parts of the result. Stop the server with Ctrl+C. Use the full lab to compare HTTP errors and transport errors.
